# 舒尔特方格

一个在 Windows 上运行的找数字小游戏。每局会打乱数字排列，可以选 4×4、5×5 或 6×6，默认 5×5。

## 怎么运行

需要带 Tkinter 的 Python 3。安装好后，双击 [schulte.pyw](schulte.pyw) 就能打开，也可以在项目目录运行：

```powershell
py -3 schulte.pyw
```

## 怎么玩

1. 选好方格大小，点击「开始」。数字会显示出来，计时同时开始。
2. 从 1 开始，按从小到大的顺序点数字。点错时格子会短暂标红，并累计误点。
3. 点完最后一个数字后，窗口会保留本局用时和误点次数。想换个排列，可以点「重开」或「再来一局」。
